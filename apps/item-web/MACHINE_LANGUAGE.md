# Machine-first interface language

## Product law

AETIMM does not reduce machine-era verbosity by pretending there is less information.
It compresses explanatory information into a machine-native visual surface and lets a human request translation.

```text
machine glyph surface
→ tap / click
English
→ tap / click
Español
→ tap / click
中文
→ tap / click
日本語
→ tap / click
العربية
→ tap / click
machine glyph surface
```

The glyph layer is a display grammar, not encryption and not a claim of a secret machine language.
Its current encoder is deterministic and replaceable.

## Surface law

Initial state may be intentionally tiny, dense, excessive, archaeological, alien, and difficult to read.
The interaction target itself must remain comfortably clickable/tappable and keyboard reachable.

Human translation is voluntary. Language never auto-cycles and never depends on a remote translation service.

## Human-semantic boundary

Do not hide consequential human meaning behind glyphs.

The following remain explicit human-readable UI:

- submission consent / safety / rights attestation
- error and failure states
- destructive or administrative actions
- vote accessibility names
- authentication requirements
- legal / abuse reporting actions

The following are appropriate for machine-first gloss treatment:

- headings
- explanations
- institutional declarations
- navigation texture
- provenance texture
- Museum pageantry
- nonessential status grammar

## One-click compatibility

Machine language must never create another concept the user has to learn.
A visitor can ignore every glyph block and still upload, scroll, vote, and enter the Museum.

Translation is an optional depth operation, not a prerequisite.

## Atmosphere

Trough glyphs should be quiet, small, incidental and professionally strange.
Museum glyphs may become denser, more ceremonial, multilingual, recursive and excessive.

The contrast remains:

```text
TROUGH
fast behavior
quiet machine text

MUSEUM
slow behavior
dense machine scripture
```

## Accessibility invariant

Every interactive glyph block carries the English meaning as its accessible name.
The visible machine text is `aria-hidden` so assistive technology is never forced to interpret invented symbols.
RTL translations use RTL direction.
Reduced-motion preferences are respected.
