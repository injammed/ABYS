# Eye of Horizons campaign

APY0C (zero) is the fictional corrupted machine antagonist. Its dark wizard controller exploits the Eye of Horizons, a fictional black-hole observation link. The public library's observation tools are a separate system.

The parallel quest advances at physical stations: infection evidence → command relay → bunker access → wizard combat → lens severance. The last station requires the boss at zero health. Severance disables robot patrols and counts as disabling the two Aegis guards, so either quest order remains playable. It does not alter population ledgers or erase infection/demons. Combined victory requires an eradicated outbreak, severed lens and protected humans. Rescue remains available after eradication, including when the original single infected is killed immediately.

The Transcendence Protocol means restoring agency and voluntary cooperation in this story. It is not a claim about quantum consciousness or a real black-hole observation capability.

Horizon state is additive to browser save version 2. Legacy saves retain campaign/player state and start the new quest. Invalid Horizon state alone resets its quest. The boss has 48 health, one telegraphed 1.5-second curse, 24 damage and a three-second cooldown. Pausing, hidden tabs and death suspend the combat loop. AK, VTOL and Starfall share the game's existing targeting rules. Bunker walls block rays and movement; its open doorway is excluded from ray collisions. VTOL flight respects the bunker roof.

Tests live in verify-capital.mjs and verify-survival.mjs, already run by the Pages workflow. They exercise independent progression, boss/lens gates, idempotency, migration, rescue cooldown, population conservation, full footprint reachability, locked/open doorway rays and boss targeting. Full visual/playtesting requires a WebGL-capable browser.
