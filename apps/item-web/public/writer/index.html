    AETIMM Writer for your laptop

    A real desktop app. Write offline, open and save files on your laptop, and launch it from your desktop or Applications folder.

    Windows installer Windows · Intel / AMD 64-bitMac · Apple silicon M1, M2, M3, M4 and laterMac · Intel Intel-based MacLinux app AppImage · x86-64

    Early release · Windows unsigned; Mac ad hoc signed, not notarized. Your operating system may block or warn about installation. No account, subscription or internet connection is needed to write. Mac: open the disk image and drag AETIMM Writer into Applications. Windows: run the installer. Linux: mark the AppImage executable, then open it.

    Browser drafts do not automatically transfer to the desktop app. File → Save manuscript downloads an .aetimm file; open that file in the app.
