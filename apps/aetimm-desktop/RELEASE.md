AETIMM Game — Mac desktop playtest.

Choose Apple silicon (M-series) or Intel, open the DMG and drag AETIMM Game into Applications. The entire current playable build is bundled locally: APY0C endgame lab, cathedral/Capital Refuge, arcade campaign, pinball and low-poly console campaign. You can play these offline. Library/feed features that depend on remote services remain website features.

The launcher checks the GitHub development channel on launch. Download an update, apply it between sessions and choose a game. Game → Return to launcher lets you leave a playtest; Updates → Check for game updates checks without interrupting play. Updates are checksum-verified and installed into separate build folders. Previous build returns to the earlier content or bundled original. Stable local save origin preserves cathedral saves/high scores; unfinished arcade/console sessions restart. Game → Export/Import saves creates or restores a backup. Browser saves do not transfer automatically.

Choose folder / SSD selects storage for future downloaded builds and copies retained builds there. The app itself installs normally in Applications. The bundled game and saves remain on the Mac. Keep the SSD connected while playing its content. Updates currently download a complete small content pack; this is not yet a multi-pack terabyte asset distribution system.

Report bugs in the AETIMM production chat; attach the diagnostic export if useful. Diagnostics are never uploaded automatically. There is no live autonomous APY0C authoring agent: source changes and new releases are made through the production chat. The endgame lab is a low-poly prototype of the three boss forms, not final cinematic visual quality. The large galactic desktop game remains in development.

Early release: Mac app is ad hoc signed and not notarized by an Apple developer identity. macOS may warn or block installation. Launcher binary upgrades require another installer; the content updater does not replace the launcher executable. No Apple signing/notarization credentials are configured.
