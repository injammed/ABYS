vnnova — a writing studio by AETIMM — is an offline desktop novel-writing app: File/Edit menus, fonts and sizes, rich text, named chapters, word counts, find/replace, recovery autosaves, native open/save dialogs, Word (.docx), plain-text and HTML exports, and printing/PDF.

Download the file for your laptop. Windows: run the .exe installer. Mac: open the matching .dmg and drag vnnova to Applications. Linux: make the AppImage executable and open it.

This early release has unsigned Windows installers and ad hoc signed, non-notarized Mac apps; operating systems may show warnings or block installation. No code-signing certificate is included. There is no auto-updater. Browser manuscripts transfer via File → Save manuscript, then File → Open in the desktop app. Keep exported .aetimm backups; recovery storage is not a substitute for backups.

Word export includes basic paragraph, font, size, bold/italic/underline and list-text formatting. DOCX import, collaboration and cloud sync are not included. System fonts must be installed locally. Manuscript files are limited to 25 MB. No manuscripts are transmitted to AETIMM or an AI service.

Renamed from AETIMM Writer in 0.1.3. Existing .aetimm manuscripts, browser drafts and desktop recovery files remain compatible; the original desktop profile and app identifier are retained.

New in 0.1.4: ten original ornate punctuation marks. Use Ornate marks to insert a raised single mark or a pair around selected words. Manuscripts, formatted HTML, printing/PDF and Word exports preserve the symbols; plain text substitutes curly quotation marks. Reinstall the new desktop version to receive this feature.

New in 0.1.5: Character glyphs adds Topknot and Eyestalk from the reference plus eight invented speaker marks. Insert a one-em inline glyph or attach a speaker to a dialogue paragraph with hanging alignment. Glyphs persist through manuscript save/recovery, HTML, print/PDF and DOCX; plain text uses descriptive names.
