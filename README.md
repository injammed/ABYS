# ABYS — the execution machine behind aetimm.com

> **BUILT BY SLOP · DIRECTED BY A HUMAN · STEEL-FOLDED IN PUBLIC**

ABYS is the deployable runtime and public construction record behind [aetimm.com](https://aetimm.com). It is deliberately built with AI assistance, but it is not allowed to hide behind the claim that “AI made it.” Every meaningful fold is expected to terminate in inspectable evidence:

```txt
PROMPT / INTENT
→ ISSUE
→ BRANCH
→ PULL REQUEST
→ TYPECHECK + BUILD
→ DEPLOYMENT
→ PHYSICAL-DEVICE VERIFICATION
→ FAILURE OR PASS
→ NEXT BOUNDED REPAIR
```

The spectacle is not that generated code exists. The spectacle is that generated plans, mistakes, migrations, repairs, and production evidence remain attached to the working artifact.

## Run the public runtime

```bash
cd apps/item-web
npm install
npm run typecheck
npm run build
npm run dev
```

The build writes a public manifest containing the real commit SHA and build timestamp when CI supplies them. Development builds identify themselves as development rather than inventing production evidence.

## Secret boundary

The repository is intentionally public. Therefore it must never contain:

- Supabase service-role keys;
- OAuth client secrets;
- SMTP passwords;
- private user records;
- quarantined media;
- private conversation history;
- hidden model reasoning;
- unsanitized telemetry or personal information.

Only browser-safe Supabase configuration may enter the static bundle. Provider secrets remain in Supabase/provider dashboards. Public provenance includes selected task packets, issues, PRs, commits, migrations, CI outcomes, deployment metadata, and field-verification summaries.

## Routing rule

Strong concepts must terminate in code, schemas, tests, docs, issues, pull requests, deployments, or measurable operational changes. Weak concepts are rejected, redirected, or compressed until they produce an executable next action.

**Built by slop does not mean trusted without verification. It means the conversion from raw generation to reliable machinery is itself public.**
